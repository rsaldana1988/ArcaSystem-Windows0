ARCASYSTEM - INICIO CON DOBLE CLIC

1. Descomprime el ZIP en una carpeta de Windows.
2. Instala Python 3.12 o 3.13 desde python.org si no lo tienes. Activa Add Python to PATH.
3. Haz doble clic en INICIAR_ARCASYSTEM.bat.
4. Espera a que se abra http://127.0.0.1:8000/ en tu navegador.
5. En el primer inicio, crea el nombre de la iglesia, usuario y contrasena.
6. Para cerrar ArcaSystem, cierra la ventana negra del iniciador.

La base de datos se guarda en db.sqlite3 dentro de la carpeta.
No elimines ese archivo si quieres conservar tus registros.
Para futuros inicios, haz doble clic en el mismo archivo BAT.

Esta es una base funcional de desarrollo, no el sistema completo ni una
instalacion certificada para datos reales sensibles.
